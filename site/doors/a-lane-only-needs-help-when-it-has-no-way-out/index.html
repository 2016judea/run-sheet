Door 02 · On the floor · sheet 3

A lane only needs help when it has no way out.

Sending a body to a lit lane pays when that lane is the only place the freight can go. Where it can route around, the light is noise.

On your dock

Two lanes lit. On the first, every piece for that destination has to come down this one chute. When it blocks, the sorter circles the freight, then kicks it to problem solve, and most of it misses the truck. Rolled. On the second lane, the same destination is spread across six chutes. When one blocks, the sorter uses the other five. The light is on. Nothing is actually wrong.

Why it is true

A full buffer only hurts when it is the only buffer. If a destination maps to one chute, that chute is a dead end and a person is the only way out. If the destination is mirrored across many chutes, congestion routes around itself and your move is solving a problem the machine already solved. The same staffing rule, the same light and the same test can be decisive on one sorter and inert on the next. The difference is not the people or the software. It is how many ways out the lane has.

try it One destination, one lane or six. Tap a lane to block it.

Monday

  1. For every chute, count how many other chutes can take its freight. One is a dead end. Five is a mirror.
  2. Rank your dead ends by volume. That list is where moving a body pays.
  3. Stop chasing lights on mirrored lanes. Chase the set when the whole set is lit.

The rule, and why

Spend labor on dead ends. Let mirrors absorb themselves.

A move costs a person walking the building and leaving the work they had. Pay it only where it buys something.

The trap

Mirrored lanes still fail, but they fail together and later. When the whole set fills, the recirc is worse because the machine kept everything moving right up to the edge. Watch the set, not the lane.
