# Dock Doors

A paradigms framework for people who run a dock, a warehouse or a fleet. Ten doors,
each one idea: the line, what it looks like on the floor, why it is true, what to
measure Monday, the rule with its reason. Not a tool. Not a data platform. No pitch.

    python3 build.py              # DOORS in build.py -> site/
    python3 scripts/deploy.py     # Vercel REST deploy (needs VERCEL_TOKEN)

The build asserts a banned-word list: nothing on the site names a company, a
building, a system, a tuned constant or a dollar figure from any source. Every
sentence must be equally true at any large parcel network.
